# POTLI redesign

This project is the POTLI customer application. The redesign intentionally preserves the existing service, controller, model, authentication, cart, order, payment, return/exchange and API contracts while replacing the customer-facing brand and presentation layer.

## Visual system
- Editorial serif display typography paired with restrained sans-serif utility text.
- Black, ivory, porcelain and neutral gray palette.
- Typography-led POTLI wordmark plus new POTLI launcher artwork.
- Minimal borders, square geometry, generous whitespace and image-first product presentation.
- Rebuilt onboarding with split editorial composition, progressive rule indicator and a dedicated POTLI entry CTA.
